what F09 actually is: F08 validates a file and gives back a raw list of errors (rule
code, layer, severity, a Mustang-generated technical message). That's fine for a
developer, useless for the person who uploaded the invoice. F09 sits on top of F08 and
turns that raw list into something a non-expert can read: each rule code is looked up
in a rule_catalog table (title_fr / description_fr / correction_hint_fr — data, not
code) and the errors come back with a French explanation and a fix hint instead of a
bare code. Never shows a bare code with no explanation — falls back to Mustang's own
message if a code isn't catalogued yet.
