BUGS FIX #2
===========

FOR THE TEAM - READ BEFORE PULLING
---------------------------------------------------------------------------------------------------------------------------------------------------------------
.env and the TLS certificates are no longer in git. On `git pull`, git deletes
your local .env. Your Docker database keeps its old password, so without your
old .env the backend cannot connect.

Existing folder - keep your .env:
   cp .env .env.backup
   git pull
   mv .env.backup .env
   (forgot? restore it: git show 9e4be9c:.env > .env)

Or a fresh clone (local data is lost):
   docker compose down -v      # in the OLD folder: frees container names, drops old DB
   git clone https://github.com/FacturXproject/FacturX.git
   cd FacturX && ./start.sh

Start the project: ./start.sh  (creates .env and certificates if missing,
then runs docker compose up --build)




PROBLEMS FOUND

1. Credentials in git
   .env and the TLS private key (nginx/certs/localhost.key) were versioned.
   .env.example had 3 of the 7 variables: with it alone, sending an invitation
   returned 500 (empty MAIL_FROM).

2. No one-command deployment
   A fresh clone needed several manual steps (.env, certificates, compose).

3. Not responsive
   Fixed 240px sidebar with no breakpoint: on a phone (375px) the content kept
   135px.

4. Organization name not validated by the backend
   Empty name or spaces accepted (200), 300 characters returned 500.

5. Public API without PUT / DELETE
   Only GET and POST, the module requires GET, POST, PUT and DELETE.

6. GDPR without confirmation emails
   Export and account deletion sent no email.

7. README incomplete
   No 42 header line, team and roles, individual contributions, modules and
   points, custom module justification, resources and AI usage.




FIXES
---------------------------------------------------------------------------------------------------------------------------------------------------------------
1. .env and nginx/certs/ removed from git and added to .gitignore.
   .env.example complete; docker-compose.yml has defaults for MAIL_* and
   APP_BASE_URL. CI creates .env and the certificates before starting.

2. ./start.sh: creates .env from .env.example and the certificates if missing,
   then runs docker compose up --build.

3. Layout.jsx: under 900px the sidebar becomes a drawer (menu button, closes on
   navigation). Wide tables scroll inside their block; stat cards and the
   Invitations toolbar wrap.

4. OrganizationService: name trimmed, spaces collapsed, 1-100 characters on
   create and rename, otherwise 400 INVALID_ORGANIZATION_NAME. Frontend
   maxLength=100.

5. PUT /api/public/v1/documents/{id} (rename, owner or admin) and
   DELETE /api/public/v1/documents/{id} (same rules as the app), scope
   DOCUMENTS_WRITE. Invalid JSON body returns 400.

6. Confirmation email after a data export and after an account deletion
   (sent to the original address). A failed email does not cancel the
   operation.

7. README: all the sections above added (in French). Quick Start, environment
   variables and F17 endpoints updated.
